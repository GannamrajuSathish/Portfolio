Fraud Detection Using Machine Learning

By Sathish Gannamraju

Project Overview

This project focuses on building a system that detects fraudulent transactions using various machine learning techniques. It uses both supervised and unsupervised learning models to analyze transaction patterns and identify anomalies.

Key Features

  • Handles real-world imbalanced data
  • Applies multiple ML algorithms like Random Forest, SVM, Isolation Forest
  • Includes feature engineering and data preprocessing
  • Supports model evaluation with accuracy, precision, recall, and F1 score
  • Optional: Flask API for real-time prediction (deployment ready)

Technologies Used

  • Python
  • Pandas, NumPy
  • Scikit-learn, XGBoost
  • Matplotlib & Seaborn (for data visualization)
  • Flask (for API)
  • Google Colab / Jupyter Notebook

Project Learnings

  • Understanding fraud patterns and behavior in data
  • Dealing with class imbalance using SMOTE and undersampling
  • Evaluating models beyond accuracy using AUC, ROC, etc.
  • Implementing end-to-end ML pipelines
