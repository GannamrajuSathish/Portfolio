Sleep-Sensing Glasses for Driver Safety

Project Overview

This project is a prototype designed to detect driver drowsiness using glasses embedded with sensors. It alerts the driver when signs of sleepiness are detected, enhancing road safety and potentially saving lives.

Key Features

  • Eye-blink detection to monitor drowsiness in real time
  • Audible alerts when prolonged eye closure is detected
  • Lightweight and comfortable eyewear prototype
  • Designed with driver usability and safety in mind

Technologies Used

  • IR sensors for blink detection
  • Arduino Uno microcontroller
  • Buzzer for alert mechanism
  • Circuit design and prototyping tools

What I Learned

  • Applied design thinking methodology for real-world problem-solving
  • Hands-on experience with hardware integration
  • Improved understanding of embedded systems and human-computer interaction
